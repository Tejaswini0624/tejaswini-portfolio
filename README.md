# Tejaswini Portfolio

A professional React + Vite portfolio for Mamidisetti Tejaswini.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Customize

- Replace the LinkedIn placeholder in `src/App.jsx` with the real LinkedIn URL.
- Add `public/resume.pdf` when the final resume is ready.
- Project live-demo/GitHub links can be added to the project data in `src/App.jsx`.

## Build

```bash
npm run build
```
